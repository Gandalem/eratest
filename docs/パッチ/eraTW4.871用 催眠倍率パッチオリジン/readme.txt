README

TWの好感度倍率と依頼好感度倍率のパッチです。
4.800の21/09/13までの4.800関連パッチを適用した環境です。
他のバージョンでの作動は確信できますのでご注意してください。

説明
文字通りに好感度の倍率を21倍まで設定できる簡単な機能です。
たが、１を入力しても2倍から始まります。たぶん海外の制作者の意図ではないかと。
公式は以下の通りです。

好感度倍率
TFLAG:97 = TFLAG:97*(1+FLAG:好感信頼上昇?+TALENT:94*2)
*LIMITは20までです。

信頼度倍率
信頼度上昇値 = 信頼度上昇値*(1+FLAG:好感信頼上昇?)

依頼好感度倍率
変動数 = 変動数*(1+FLAG:依賴好感信頼上昇?)

改造点
FLAGに22、好感信頼上昇?と23,依賴好感信頼上昇?を追加。
SHOP関連のOPTIONにCASE 32、CASE	33と関連変数を追加。
ステータス計算関連のTRACHECK_信頼度上昇処理とTRACHECK_好感度上昇処理に関連変数を追加。
ERBのCOMMONに依頼好感度倍率を追加。
